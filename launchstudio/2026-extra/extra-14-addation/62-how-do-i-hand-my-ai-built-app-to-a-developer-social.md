🩺 SECOND OPINION

PATIENT
Opvangplan, a scheduling and parent communication tool for small childcare centres, built by Inge Brinkhuis in Lovable. One year old, eight centres.

FIRST OPINION
After one week, the newly hired freelance developer (two days a week) recommended rewriting everything in a different framework. Estimated recovery time: three months.

SECOND OPINION, by LaunchStudio
The code was workable. The developer had struggled for other reasons:
• The repository sat on Inge's personal account
• The database had policies created both by prompts and by hand
• There was no staging
• Nothing was documented
• He had been given Inge's own Supabase login

PRESCRIPTION (6 business days, €2,250)
💊 The repository moved to a company organisation
💊 The database reconciled into migrations
💊 Staging with test data
💊 A README, plus an operating document with a systems list and known issues
💊 Individual access for the developer
💊 A working agreement: Lovable only for interface changes on main

RECOVERY
The developer withdrew the rewrite proposal. Within a month, he'd shipped a long-requested attendance export and fixed two known issues, all through staging.

"He didn't need a new framework. He needed a map of what I'd built and somewhere safe to try things." - Inge Brinkhuis
