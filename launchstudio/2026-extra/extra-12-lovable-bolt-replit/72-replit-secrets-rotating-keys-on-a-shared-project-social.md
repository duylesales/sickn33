📜 The life of one connection string

BORN
Pasted into a configuration file while a founder was getting a deployment to work. The project had started as a public template he was learning from.

CHILDHOOD (4 months)
Public, along with the rest of the project. Forked eleven times.

ADULTHOOD (18 months)
Forgotten. Still sitting in the file. It opened a database holding pupils' names, addresses, school details and transport needs, special category data in every respect that matters.

DISCOVERED
In a routine review, one the founder nearly didn't do.

RETIRED
Rotated immediately, before anything else.

The project was Leerlingvervoer, which Ruben Hooghiemstra built on Replit: transport planning for pupil transport contractors serving special education schools, seven contractors, around 600 pupils. 🚌

The rest of the response (LaunchStudio, 2 business days, €2,900):
✓ The string moved into the secrets mechanism, and the project history searched for other pasted values. That found a second one, an email provider key from the same period
✓ Both credentials rotated and provider logs reviewed: no access from unrecognised sources in the available window
✓ The project confirmed private, the eleven forks identified, and the platform contacted about the two that were public
✓ Four collaborators from earlier work, no longer needing access, removed
✓ Separate scoped credentials per integration, replacing one shared admin key
✓ Development and production values truly separated
✓ A rotation performed to set the procedure, plus an inventory of seven credentials with where each is used and when it was rotated
✓ A documented breach assessment concluding notification was warranted given the data category, made to the contractors and the Autoriteit Persoonsgegevens

No evidence of access was found. Ruben told the contractors himself before they could hear it elsewhere, and all seven stayed. Being public for those four months, he says, was never a decision he consciously made: the project simply started that way.

"It was public for four months while I was learning, and I pasted a connection string into a file during that time. Eleven people forked it. I found out eighteen months later, in a review I nearly did not do." - Ruben Hooghiemstra
