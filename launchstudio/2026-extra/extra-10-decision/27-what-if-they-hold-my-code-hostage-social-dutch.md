🔐 "Wat als de ontwikkelaar mijn code gijzelt?" Een terechte angst die ontstaat doordat software abstract en onzichtbaar lijkt.

"Code-gijzeling" valt in de praktijk uiteen in 3 concrete scenario's:
1️⃣ De developer weigert na betaling de code over te dragen.
2️⃣ De enige inloggegevens van uw database en hosting verdwijnen met de freelancer mee.
3️⃣ U bezit de bestanden wel, maar niemand anders kan de ongedocumenteerde code onderhouden.

De 4 structurele waarborgen die gijzeling technisch onmogelijk maken:

❌ Laat nooit een developer de code in diens eigen GitHub-account bouwen om het "later over te dragen"
❌ Laat nooit hosting (Vercel), database (Supabase) of betalingen (Stripe) op naam van de developer registreren
✅ Eis dat de repository vanaf commit 1 eigendom is van úw GitHub-organisatie
✅ Alle cloud-diensten op úw naam, met de developer uitsluitend als 'collaborator'
✅ Contractuele garantie: 100% intellectueel eigendom vanaf het moment van creatie
✅ Overdrachtsdocumentatie als verplichte, getoetste deliverable
