❌ Drie datumlibraries, twee iconenlibraries, vier tabelcomponenten, zes Supabase-clients

✅ Row Level Security per bureau, zodat geen enkele functie data van een ander bureau kan laden
✅ Tests voor toegangscontrole en factuurberekeningen vóór het refactoren
✅ Gedeelde datamodules, één module voor bedragen, één datum- en één iconenlibrary
