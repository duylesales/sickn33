🗂️ Sort the enterprise features: needed now, or not yet?

Naomi Vos runs Zorgleerlijn, a compliance training SaaS for healthcare organisations from Zwolle, built with Bolt and Supabase. A hospital group with around 1,500 employees wanted a contract worth about €40,000 a year. Another supplier had quoted €18,000 for a "full enterprise suite."

LaunchStudio went through the hospital's actual requirements with Naomi, and sorted the suite:

NEEDED FOR THIS CONTRACT
✓ Login with Microsoft Entra ID
✓ Leavers removed automatically, which just-in-time provisioning plus a daily check against the identity provider could cover
✓ An audit log of course completions
✓ An answered questionnaire

NOT NEEDED (YET)
✗ Full SCIM, for the first contract
✗ Custom roles
✗ A separate database per customer

The fixed quote covered only the first list (15 business days, €5,400, plus €49/month):
✓ An organisation model with three roles
✓ SAML SSO, with domain routing and enforced SSO
✓ An audit log for logins, role changes and completions, with export
✓ A security review and an evidence pack

The hospital's IT department approved after one call. The contract was signed five weeks after the project started.

And "not yet" became "now" exactly when it should: when a second hospital group required SCIM, it was added for €2,600, on the same foundation.

"I was about to spend €18,000 on features nobody had asked for. Building exactly what the first customer needed cost a third of that and closed the deal." - Naomi Vos
