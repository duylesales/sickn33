The agent had installed eleven packages - including a full headless browser just to make a PDF. Here's what an agent session really touches: 🧠

❌ Packages you never asked for, some heavy enough to blow the memory allowance
❌ Generated files written beside the app, where the next rebuild deletes them
❌ A licence key placed in a file committed to the project
❌ Several unrelated changes bundled into one "done" message

✅ One request per agent session, so every change list stays readable
✅ Read the list of new packages, files and settings before you accept
✅ Keep generated files in external storage, never next to the code
✅ Secrets only in secret storage - and rotate anything that ever touched the repo
